# Protosem Project Works

## Overview

This repository documents my engineering projects and practical work associated with Protosem. It serves as a centralized record of electronics prototyping, hardware development, PCB design, mechanical CAD, robotics, and intelligent manufacturing systems.

The objective is to develop practical engineering solutions through iterative design, prototyping, testing, and documentation.


## Development Approach

Each project should include its objective, requirements, design files, implementation details, test results, limitations, and future improvements.

Designs and results will be updated as development progresses. Proposed features will be distinguished from implemented and verified features.

## Tools and Technologies

* KiCad — electronic schematic and PCB design
* Fusion 360 — mechanical CAD and product design
* Python — scripting and AI development
* ROS 2 — robotics software and simulation
